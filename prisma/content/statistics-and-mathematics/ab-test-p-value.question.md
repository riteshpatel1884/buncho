You A/B test a new ranking model for two weeks. Each group has 50,000 users.

| | Users | Conversions | Conversion rate |
|---|---:|---:|---:|
| Control (old ranker) | 50,000 | 2,000 | 4.00% |
| Treatment (new ranker) | 50,000 | 2,100 | 4.20% |

A colleague says: "p = 0.11, so there is an 89% chance the new model is better," and wants to ship. Another says: "Let's check daily and stop when it turns significant."

1. Interpret the result correctly.
2. What is wrong with both colleagues' reasoning?
3. How should the experiment have been designed, and what would you recommend now?
